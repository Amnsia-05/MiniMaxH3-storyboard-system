# MiniMax H3 小说转分镜流水线

把一本小说稳定地、可复现地变成一整部可生成的海螺 H3 提示词资产。

## 本 skill 是总控，不是执行手册

主模板管**流程与格式**，10 个分 skill 管**具体怎么写**。执行时按需加载，不要一次全读。

### skill 家族（同目录 `~/.workbuddy/skills/`）

| 阶段 | skill | 管什么 |
|---|---|---|
| ① 拆书 | `h3-novel-split` | 集数测算、压缩比校准、单集节奏骨架、集级/段级大纲、卡点五型 |
| ② 分镜 | `h3-camera-edit` | 运镜术语表、时间戳规则、15秒3镜切分、衔接镜 10 型、动作延续衔接法 |
| **③ 备参考图** | **`h3-refsheet-gen`** | **三视图 / 表情集 / 场景图 / 道具图怎么制作**、image2/豆包 实操参数、3D 次世代动漫等风格 token、9 图分配策略、图↔描述串镜像原则、验收测试 |
| ④ 写提示词 | `h3-character-asset` | 角色卡、外貌、皮肤、伤口、服装、资产锁定、Ref2VA 保留强度 |

| | `h3-env-scene` | 室内外场景库、光影系统、天气、空间关系、声景 |
| | `h3-screen-text` | 手机屏三档方案、看手机画面、画面内文字、后期合成 |
| ⑤ 检查 | `h3-antibug-check` | 否定句写法、采样步数伪翻车、硬阻断清单、三层自检 |
| **题材专精** | `h3-romance-tension` | **恋爱/情感剧的张力戏拍法**：平台合规边界判定、六大张力技法（距离/眼神/微接触/气息/反差破防/未完成）、10 个常见情境库、原文改写三原则 |

**调用原则**：写哪一块就加载哪一个。例如要写"角色在雨夜街头看手机"，同时加载 `h3-env-scene` + `h3-screen-text` + `h3-action-body`。

> ⚠️ **恋爱 / 情感类题材必须加载 `h3-romance-tension`。**
> 这类剧的看点在张力，而红线只划掉了亲密维度的一小块
> （限定词：**集中细致** + **单纯感官刺激** + **明显性挑逗**，缺一不违规）。
> 早期拆解曾把成人情节整段"省略"，结果丢了全部看点——
> 正确做法是**保留张力、去掉露骨**，核心技法是**拍「差一点」，不拍「已完成」**。

> ⚠️ **③ 不要跳过**。角色卡与场景卡只规定"登记哪些字段"，
> **参考图本身从哪来**由 `h3-refsheet-gen` 负责。
> H3 的一致性是靠图锁的——移除视觉锚定后，角色一致性从 **7.99 崩到 0.55**。
> **没有参考图，锁定块描述串写得再精确也是空中楼阁。**

## 八步流程

> **⚠️ 开工前置（强制，不在八步编号内，但动手前必须先定）：确认动漫风格**
> 画风决定参考图提示词、H3 视觉描述、角色一致性。在集数拆解前先和用户确认本剧画风：
> 日系二次元赛璐璐 / 3D 次世代厚涂 CG / 韩系朦胧浪漫 / 国漫水墨工笔 / 美式卡通绘本 等，
> 确认后写进锁定块「画风串」，且与 image2/豆包 生图提示词用同一套中文词，全程不换。
> 我们做《挟恩图报》时漏问过此步、事后整批返工——列为强制确认项，不得跳过。

1. **集数拆解**（模块一）—— 确认单集时长 T 与集数 M；`T ÷ 15` 必须整除；压缩比先做 3 集样片校准
2. **大纲**（模块二）—— 集级大纲 + 段级大纲；每段只承载 1 信息点 + 1 情绪转折
3. **15 秒 3 镜分镜**（模块三）—— A入镜 / B主镜 / C出镜；先定衔接类型再定秒数
4. **建角色卡与资产表**（模块五）—— 每个角色、资产、场景都要有 ID
5. **写中文详版提示词**（模块六）—— 锁定块 + 每镜六段 + 声音层，1200–2500 汉字。**此稿即每镜的【中文版（人类看）】**，给人审、改、确认
6. **转官方格式**（模块七）—— 指令首行 + 三核心字段；`<d>` 对白标签不可省。**此稿即每镜的【H3版（H3看）】**，直接喂 H3
7. **漏洞检查**（模块八）—— 三层：结构 → 内容 → 看片
8. **交付**（模块十）—— `.md` 给 AI 读 + `.html` 给人读

## 不可违背的硬约束

- **H3 单次生成 4–15 秒整数**（API）／本地部署 5–15 秒。1–2 秒衔接镜必须生成 4 秒后裁切
  - ⚠️ 包含 **T2 单镜重生成**：修一个 2 秒衔接镜时要请求 `duration=4`，不能填 2。分镜表要标「生成时长（≥4s）」和「裁切后时长」两个数
- **提示词上限 7000 字符**（按字符计，1 汉字 = 1 字符）
- **图生视频与全能参考互斥** —— `first_frame`/`last_frame` 与 `reference_*` 不可同时出现
- **FL2VA 官方默认单镜**，多镜头需显式指定
- **对白必须包在 `<d>` 与 `</d>` 之间**；描述放标签外，语言标签 + 原话放标签内
- ⚠️ **台词里不要加英文双引号** —— 双引号在 H3 语义里专属「画面内可见文字」（招牌/字幕/霓虹），在 `<d>` 里套用可能诱导模型把台词渲染成画面上的字。官方示例无引号
- ⚠️ **无配乐写 `N/A`，不是 `no music`** —— 官方原文 "Use N/A when there is no non-diegetic music."
- **第一个镜头不加时间戳**，后续用 `At 00:SS.mmm`（三位小数）；指令首行用 `S.SS`（两位小数）
- **每镜最短 1.5 秒**（硬下限），设计下限 2.0 秒，承载信息镜 ≥3.0 秒
- **一镜只给一个运镜**

## 防翻车铁律

- **否定句**：正向锚定为主，每镜最多 1 句 `Do not`，放末尾，前面必须有正向描述
- **手部问题只用正向锚定**，绝不写含 `six fingers` / `extra fingers` 字样的句子
- **手机屏**：不写短信原文；用干净底板（后期贴图）或主动声明 `illegible`
- **资产**：一镜内需稳住的小物件 ≤2 件；小物件必须走参考图，纯文本不可靠
- **返工顺序**：先抬采样步数（出片 6–8 步）→ 再换种子 → 最后才改提示词
- **硬阻断项**（可读文字、跨生成左右方位、180° 轴线、物理接触）→ 改分镜绕开，不要死磕提示词

## 输出规范

- 每个镜头必须写**备选方案**
- 分镜表必须过三校验：时长和 = 15s、台词 ≤47 字、每镜有备选
- **每镜必带两份提示词，成对出现、相邻放置**：
  - **【中文版（人类看）】** —— 纯中文自然语言，按「主体/动作/对白/环境/运镜/光影」顺序写白话稿，给人审、改、确认、沟通
  - **【H3版（H3看）】** —— 官方格式英文（本模板六段式 / 模块七三字段），直接喂 H3
  - 两份描述**同一镜**，H3版由中文版转写，**不是两套独立创作**；改一处要同步另一处
  - 中文版源头、H3版终点：先写中文版把控细节与剧情，再转写 H3版，不要反过来
  - 范式见 `MiniMaxH3_分镜脚本_15s3镜.md` 的「二、逐镜详解（中文版）+ 三、可直接粘贴的 H3 提示词（H3版）」
- 所有查不到出处的参数，标注【待验证】并给出实测方法，**绝不编造数字**
