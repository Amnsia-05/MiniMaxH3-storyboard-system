# H3 恋爱/情感剧张力戏拍法

## 0. 三十秒速查

```
🔑 红线只划掉了亲密维度的一小块，不是全部。
   剩下的大空间（张力 / 暧昧 / 推拉 / 克制）恰恰是恋爱剧的看点。

审核原文的三个限定词（缺一不违规）：
  ① 集中细致展现  ② 以单纯感官刺激为目的  ③ 有明显性挑逗效果

→ 有叙事目的 + 点到即止 + 非集中细致 的亲密表达，是安全的。

核心技法一句话：拍「差一点」，不拍「已完成」。
  在预期高潮前切走，让观众自己脑补——脑补比直给更上头。

⚠️ 六大技法全部标注风险等级，每条都给了合规提示词。
   涉及敏感部位、持续接触、暴露着装的一律未收录。
```

## 1. 为什么「省略」是错的（先纠正一个常见判断）

### 1.1 平台红线的真实范围

主流平台（抖音 / 快手 / 微信）与《网络短视频内容审核标准细则》的相关条款，原文关键句是：

> 「以单纯感官刺激为目的，**集中细致展现**接吻、爱抚、淋浴及类似的与性行为有关的间接表现或暗示的，有**明显的性挑逗**、性骚扰、性侮辱或类似效果的画面、台词、音乐及音效的」

**拆出三个限定词，缺一不构成该条违规**：

| 限定词 | 含义 | 反推可做什么 |
|---|---|---|
| **集中细致展现** | 时长集中 + 细节密集 | 点到即止、非连续、单镜短 |
| **以单纯感官刺激为目的** | 无叙事功能 | **有叙事目的**（推进关系 / 揭示心理）的亲密表达 |
| **明显性挑逗** | 效果明确 | 含蓄、留白、靠观众脑补 |

另外几条明确禁止的（**这些不在本 skill 范围内，一律不碰**）：
直接展示性行为、展示或聚焦敏感部位、着装过分暴露、以隐晦低俗语言使人产生性联想、渲染性癖好。

### 1.2 「省略式」改法丢失了什么

早期拆解中，遇到原文的成人情节时采用了「省略式」——只拍前因后果，中间用空镜桥接。

| | 省略式 | 本 skill 的做法 |
|---|---|---|
| 出浴戏 | 只拍进浴室 / 出来 | 拍**门缝的光、水汽、外面的人的反应** |
| 整夜戏 | 时间流逝空镜 | 拍**天亮后的一只手、床边的两双鞋、窗帘透光** |
| 亲密接触 | 改成已完成态 | 拍**差一点的接近** + 打断 |

**关键差异**：省略式把"亲密"整个维度拿掉了；正确做法是**保留张力、去掉露骨**。

> 一句话总结：**最高级的欲望从来不是靠暴露，而是用眼神、台词和肢体语言让人疯狂脑补。**
> 这句话既是审美判断，也是合规策略——脑补发生在观众脑子里，不在画面里。

## 2. 合规边界判定表（写之前先查这张表）

| 内容 | 判定 | 说明 |
|---|---|---|
| 眼神对视、视线躲闪、瞳孔变化 | ✅ 安全 | 张力最主要的载体 |
| 距离接近但未接触 | ✅ 安全 | 本 skill 核心技法 |
| 呼吸可闻、气息交错 | ✅ 安全 | 写"距离近到能听见呼吸" |
| 指尖轻触、手背相碰 | ✅ 安全 | 微观接触，非爱抚 |
| 整理衣领 / 领带 / 头发 | ✅ 安全 | **本 skill 推荐**，且规避手部硬阻断 |
| 肩靠、额头相抵 | ✅ 安全 | 非敏感部位 |
| 耳语 | ✅ 安全 | 距离 + 声音双重张力 |
| 拥抱（短、非持续） | ⚠️ 谨慎 | 短于 2 秒、有叙事目的、无触碰动作 |
| 吻（额头 / 脸颊） | ⚠️ 谨慎 | 点到即止，不延展 |
| 吻（唇，短暂） | ⚠️ 高危 | 平台高频下架项。**建议用"差一点"替代** |
| 吻（唇，细致） | ❌ 禁止 | 命中"集中细致展现" |
| 躺卧纠缠、床戏 | ❌ 禁止 | 建议改为前后状态 + 空镜 |
| 出浴 / 淋浴（细致） | ❌ 禁止 | 改为门外视角 / 水汽 / 音效 |
| 敏感部位特写 | ❌ 禁止 | — |
| 过分暴露着装 | ❌ 禁止 | — |
| 隐晦低俗台词 | ❌ 禁止 | 双关、性暗示类台词全部剔除 |

> **不确定时怎么用**：问一句「这段删掉，剧情还成立吗？」
> 成立 → 说明它只是感官刺激，删。
> 不成立 → 说明它有叙事功能，保留但降级到"差一点"。

### 2.1 判定练习（三个限定词怎么用）

遇到拿不准的内容，逐条问这三个问题：

```
Q1 是不是「集中细致」？（时长集中 + 细节密集 + 连续展现）
Q2 是不是「以单纯感官刺激为目的」？（删掉后剧情还成立吗）
Q3 是不是「有明显性挑逗效果」？（含蓄还是直白）

三问全"是" → 违规，改
任一为"否" → 可保留，但按本 skill 技法降级
```

**五个例子**：

| 例子 | Q1 集中细致 | Q2 单纯感官刺激 | Q3 明显性挑逗 | 判定 |
|---|---|---|---|---|
| 8 秒连续唇吻特写，无台词无剧情推进 | 是 | 是 | 是 | ❌ 违规，改"差一点" |
| 2 秒额头相抵，表现她终于放下防备 | 否（短） | 否（有叙事功能） | 否 | ✅ 可保留 |
| 他靠近到一掌宽停住，铃声打断 | 否 | 否 | 否 | ✅ **推荐写法** |
| 她整理他的领带，全程 6 秒手部特写 | 部分 | 否（关系外化） | 否 | ⚠️ 压到 2 秒 + 用已完成态 |
| 出浴后 5 秒的水珠特写 | 是 | 是 | 是 | ❌ 改为门外视角 / 拍反应 |

> **最容易被误判的是"整理衣物"类动作**。
> 它本身安全，但一旦**时长拉长 + 特写聚焦**，就容易滑向 Q1。
> 所以本 skill 一律要求：整理类动作压到 **2 秒以内**，并用已完成态（§3.7）。

## 3. 六大张力技法（本 skill 核心）

> 每条给：原理 / 可直接复制的提示词 / 景别与运镜 / 风险 / H3 技术提示。

### 3.1 技法一：距离（Proximity）

**原理**：张力产生于"距离在缩短但尚未归零"。距离归零的那一刻，张力反而消失了。

```text
【EN】
He steps in until his face is a hand's width from hers; he stops there and does not
close the remaining distance. She does not move back.
The camera holds a two-shot, then pushes in with small amplitude at slow speed.
By the end of the shot the gap between them is unchanged.
Do not let either of them move closer or further at any point in the shot.

【中】
他靠近到脸与她的脸只剩一掌宽，停住，不再缩短剩下的距离。她没有后退。
镜头先是双人中景，然后小幅缓慢推近。到本镜结束，两人间距保持不变。
本镜全程双方不再靠近也不退开。
```

| 项 | 值 |
|---|---|
| 景别 | 双人中景 → 中近景 |
| 运镜 | Push In small/slow（**推到一半停住**，不要推到底） |
| 风险 | 低 |
| H3 提示 | 「间距不变」写进收尾，正向锚定 + B 类 `Do not`，最稳的一类 |

**变体**：
- **背后接近**：他从她身后靠近，她察觉但未回头
- **退无可退**：她后退，背抵到墙 / 门 / 桌沿
- **擦身而过**：两人错身，肩膀几乎相碰但未碰

### 3.2 技法二：眼神（Gaze）

**原理**：眼神是张力成本最低、安全系数最高的载体。搜索资料里说：*性感在于眼睛的旅程，不在身体*。

```text
【EN】
A large close-up frames her face. She is looking away, then her eyes move sideways
toward him without her head turning, then she looks away again.
Her lashes lower once. The camera holds a static shot.
By the end of the shot her gaze is averted as it was at the start.
Do not let her turn her head toward him at any point in the shot.

【中】
大特写框住她的脸。她看向别处，然后眼睛横向移向他而头没有转过去，
随后又移开视线。睫毛垂下一次。镜头固定。本镜结束时她的视线回到起始的偏移状态。
本镜全程她的头不转向他。
```

| 项 | 值 |
|---|---|
| 景别 | 大特写（眼）→ 面部特写 |
| 运镜 | Static Shot（固定最稳，眼神戏不需要运镜） |
| 风险 | 低 |
| H3 提示 | 眼睛动作要**分拍**（`then` 串联），不要写"同时" |

**三个高价值眼神模式**：

| 模式 | 写法 | 张力来源 |
|---|---|---|
| **偷看后移开** | `her eyes move sideways toward him, then away` | 未说出口的在意 |
| **对视不下移** | `their eyes meet and neither looks away` | 僵持 / 摊牌前 |
| **视线落在不该看的地方后迅速抬起** | `her gaze drops to his collar, then lifts at once` | 慌乱 / 心事败露 |

> ⚠️ 第三种要谨慎写落点。落点只写**衣领 / 手部 / 喉结**这类非敏感位置，
> 且必须"迅速抬起"——停留即变成"聚焦"，有擦边风险。

### 3.3 技法三：微观接触（Micro-contact）

**原理**：*指尖相触比直接拥抱更具挑逗性*。接触面积越小、时长越短，张力越强，风险越低。

```text
【EN】
A close-up frames both their hands on the table, a finger's width apart.
His hand shifts a little closer, then stops. The backs of their hands touch
once and stay touching.
The camera holds a static shot.
By the end of the shot the two hands are still touching and neither has moved away.
Do not let the hands interlace or the fingers separate at any point in the shot.

【中】
特写框住桌上两人的手，相距一指宽。他的手移近一点，然后停住，
两只手背相碰一次并保持接触。镜头固定。
到本镜结束两只手仍相触，双方都没有移开。
本镜全程双手不交握、手指不分开。
```

| 项 | 值 |
|---|---|
| 景别 | 手部特写 |
| 运镜 | Static Shot |
| 风险 | 中（手部是 H3 崩坏重灾区） |
| H3 提示 | **必须用手部三档降级**：写"手背相贴、手指并拢、五指"，不写交握 |

**微观接触安全清单**（按风险从低到高）：

```
✅ 手背相贴 / 指尖轻触 / 递东西时手指短暂相碰
✅ 肩膀相靠 / 手臂外侧相贴
✅ 额头相抵
⚠️ 整理衣领（手部靠近颈部，写"指尖捏住衣领边缘"，不写"触碰颈部"）
⚠️ 拂开额前碎发（写"指尖拨开"，不写"梳理/抚过"）
❌ 腰部 / 腿部 / 任何贴身位置
```

> **整理领带/衣领是本 skill 最推荐的动作**，原因有三：
> ① 天然叙事（亲密关系的外化）② 避开敏感部位 ③ **规避持续接触硬阻断**
> ——开场就写成"领带已经是松的，她只做整理"，见 §3.7 已完成态。

### 3.4 技法四：气息（Breath）

**原理**：呼吸可闻 = 距离极近的听觉证据。它把"距离"从视觉转成听觉，尺度感更强但画面更干净。

```text
【EN】
A medium close-up frames them from the side, close enough that each can hear
the other breathing. She breathes in once, shallow and unsteady.
He does not move. A few strands of her hair lift and settle on the air between them.
The camera holds a static shot.
By the end of the shot neither has moved and the distance is unchanged.
Do not let either of them speak at any point in the shot.

【中】
中近景从侧面框住两人，近到能听见彼此的呼吸。她浅而乱地吸了一口气。
他没有动。几缕发丝在两人之间的空气里扬起又落下。镜头固定。
到本镜结束双方都没有移动，间距不变。本镜全程两人都不说话。
```

| 项 | 值 |
|---|---|
| 景别 | 侧面中近景 |
| 运镜 | Static Shot |
| 风险 | 低 |
| H3 提示 | **声音层是这类镜头的主战场**——见 §5 |

**发丝是最好用的次级运动**：几缕发丝在空气里扬起，既证明距离极近，又是"环境反应"段的标准内容（我们体系本来就要求每段写次级运动）。

### 3.5 技法五：反差破防（Contrast Break）

**原理**：强势者露出脆弱，比弱势者一直脆弱张力强得多。**破防的瞬间才是看点**，不是破防后的状态。

```text
【EN】
A medium shot frames her standing with her arms folded, chin raised, her
expression set. Then her hands loosen on her own arms, then her chin drops
a little, then she looks away first.
The camera pushes in with small amplitude at slow speed.
By the end of the shot her arms are still folded but her gaze is fixed on the floor.
Do not let her expression soften into a smile at any point in the shot.

【中】
中景框住她双臂交叉站立，下巴抬起，表情绷着。然后她环住自己手臂的手松开了些，
然后下巴微落，然后她先移开了视线。
镜头小幅缓慢推近。到本镜结束她仍抱着双臂，但视线定在地面。
本镜全程她的表情不要软化成笑。
```

| 项 | 值 |
|---|---|
| 景别 | 中景 → 中近景 |
| 运镜 | Push In small/slow |
| 风险 | 低 |
| H3 提示 | 收尾句很关键：**锁住"没完全破防"**——她仍抱着双臂，只是视线落了 |

**破防的四个层次**（从外到内，逐层递进）：

```
① 手部：环住自己手臂的手松开 / 指节发白 / 攥紧衣角
② 肩颈：肩膀塌下一点 / 下巴落下 / 喉结滚动一次
③ 视线：先移开视线 / 视线落在对方身上不再躲
④ 呼吸：一次浅而乱的吸气 / 呼吸变浅
```

> **注意**：不要一次推到底。四个层次分在**不同镜次**里逐层递进，
> 比一个镜头里全演完张力更强——这也正好符合"15 秒只承载 1 个情绪转折"的约束。

### 3.6 技法六：未完成（Near-Miss / Interruption）★核心

**原理**：*在预期的高潮前切走*。这是"欲望的引擎"——未完成的动作让观众自己补完，而脑补永远比直给更强烈。

```text
【EN — 镜 A：接近】
A medium close-up frames them face to face. He leans in a little, then stops
with his face a hand's width from hers. She does not move back.
The camera pushes in with small amplitude at slow speed.
By the end of the shot he has not closed the remaining distance.
Do not let him close the remaining distance at any point in the shot.

【EN — 镜 B：打断】
At 00:13.000, the shot cuts to a wide shot as a door opens off-frame and a
voice calls her name. Both of them step apart at once.
The camera holds a static shot.
By the end of the shot they are standing a full pace apart, facing the doorway.
```

| 项 | 值 |
|---|---|
| 景别 | A 中近景 → B 全景 |
| 运镜 | A Push In 停住 / B Static |
| 风险 | 低（**最安全且最有效**） |
| H3 提示 | 打断要用**声音先导**：门响 / 电话 / 脚步，让切镜有叙事理由（满足"剪辑必须引入新信息"） |

**打断的四种方式**（都可作为段落卡点）：

| 方式 | 写法 | 额外收益 |
|---|---|---|
| **声音先导** | 门铃 / 电话 / 脚步声先入 0.3s | 可做 J-cut，剪辑更顺 |
| **第三方入场** | 门开，有人叫她名字 | 制造外部压力 |
| **自己退开** | 她先恢复理智，退开一步 | 人物主动性 + 内心冲突 |
| **视线转移** | 她的视线越过他，落在别处 | 揭示她心里有别人（虐点） |

> **这一条是本 skill 最想传递的**：
> 不是"想拍的不能拍所以少拍"，而是**"未完成"本身就是更强的表达**。
> 平台红线逼你停下，而停下恰好是张力最高的位置。

### 3.7 已完成态：把「过程」改成「结果」

> 这是 `h3-action-body` 的降级手法，在恋爱剧里特别好用——
> 因为它同时解决了**合规**与 **H3 持续接触硬阻断**两个问题。

**原理**：不拍"怎么做到的"，只拍"已经这样了"。

| 原动作 | 已完成态改写 |
|---|---|
| 他解开她的安全带 | 安全带**已经**解开，他正收回手 |
| 她替他整理领带 | 领带**已经**是松的，她只做最后一下整理 |
| 他握住她的手 | 他的手**已经**覆在她手背上 |
| 他揽住她的腰 | 他的手**已经**在她腰侧，她正要挣开 |

```text
【EN — 整理领带，已完成态】
A medium close-up frames her standing in front of him. His tie is already loosened
and pulled to one side. She reaches up, takes the knot between her fingers,
and straightens it once. Then she lets go and lowers her hand.
He stays still throughout.
The camera holds a static shot.
By the end of the shot the tie sits straight and her hands are at her sides.
Do not let her hands stay at his collar at any point in the shot.

【中】
中近景框住她站在他面前。他的领带已经是松的、歪向一侧。
她抬手，指尖捏住领结，整理了一下，然后松开手放下。整个过程他保持不动。
镜头固定。到本镜结束领带已正，她的双手垂在身侧。
本镜全程她的手不要停留在他的衣领处。
```

**为什么这样写有三个好处**：
1. 手部从"精细操作"降为"捏住→整理→松开"的**短动作**，落在三档降级的第 2 档
2. 接触时长被压缩到 1–2 秒，**规避持续接触硬阻断**
3. 合规上属于"整理衣物"，完全安全

### 3.8 技法组合表（怎么搭配）

单个技法张力有限，**组合才是关键**：

| 组合 | 适用情境 | 强度 |
|---|---|---|
| **距离 + 眼神** | 初次心动的试探 | ★★☆ |
| **距离 + 气息** | 对峙 / 质问 | ★★★ |
| **眼神 + 反差破防** | 强势者第一次动摇 | ★★★ |
| **微接触 + 未完成** | 递东西 / 整理衣物 | ★★★ |
| **距离 + 气息 + 未完成** | **最高张力**（推荐主力组合） | ★★★★ |
| **反差破防 + 打断** | 情绪要爆发却被外力掐断 | ★★★★ |

> **主力推荐：距离 + 气息 + 未完成**。
> 靠近 → 停在一掌宽 → 呼吸可闻 → 停顿 → 打断。
> 这五拍覆盖了张力的全部要素，而且**全程无需接触**，
> 同时规避了合规红线与 H3 的持续接触硬阻断。

## 4. 节奏：留白比密度重要

### 4.1 张力的节奏曲线

```
推 → 停 → 推 → 停 →（打断 / 转场）
         ↑         ↑
      张力峰值   最高峰值
```

**不要匀速推进**。推一下停一下，停顿处才是张力峰值——因为它给观众时间意识到"他们快碰到了"。

| 位置 | 处理 |
|---|---|
| 段落开头 | 建立距离（远 → 近） |
| 段落中段 | **停在"差一点"**，给足时长（停顿越久张力越强） |
| 段落结尾 | 打断，或转场到下一场景 |

### 4.2 慢动作是香料，不是主菜

搜索资料的提醒值得记住：*slow-motion is a spice, not the main course*。

- ✅ 只在**关键一瞬**用（手背相触的那一下、视线移开的那一下）
- ❌ 整段慢放 = 拖沓
- **关键**：慢放要有**速度对比**——前面正常速度，突然慢下来，效果才出来

> H3 限制：模型无法精确控制变速。**用"剪辑实现节奏，不用提示词实现变速"**——
> 生成一个正常速度的镜头，在剪辑台做速度曲线。这是 §6 的硬阻断项。

### 4.3 留白的三种手法

```
① 切走留白：在最高潮前切到空镜 / 物件 / 窗外
② 声音留白：BGM 全部撤掉，只留呼吸与衣物摩擦
③ 视线留白：人物看向画外，观众看不到他看的是什么
```

## 5. 声音设计（这类戏的隐藏主战场）

> 恋爱戏的张力有一半在声音层。画面受红线约束越大，声音越该承担张力。

### 5.1 `overall_soundscape` 该写什么

| 声音 | 写法 | 作用 |
|---|---|---|
| 呼吸 | `one shallow, unsteady breath` / `a slow exhalation held back` | 证明距离极近 |
| 衣物摩擦 | `the soft rustle of a coat sleeve` | 证明有动作 / 距离近 |
| 心跳（主观） | `a single slow heartbeat, close and low` | 主观张力（谨慎用） |
| 吞咽 | `he swallows once` | 紧张 / 克制 |
| 环境静止 | `the room goes quiet except for the rain` | 留白 |

**示例**：

```text
overall_soundscape: The room falls quiet except for rain against the window.
One shallow breath, close to the microphone. The soft rustle of a coat sleeve
as an arm lowers. A floorboard creaks once under a shifting weight.
```

### 5.2 `non_diegetic_music` 的处理

```
接近/对峙段：  撤掉 BGM，或只留一个持续低频（留白）
情绪释放段：   弦乐进入，慢速
打断/破防瞬间：音乐在切点前 0.2s 干净切断 —— 突兀感就是张力
```

> ⚠️ 配乐字段**只写乐器 / 速度 / 节奏 / 动态**，不写情绪词（官方红线：
> "do not use abstract mood words or explain the emotional function of the score"）。

### 5.3 台词的处理

**少写，甚至不写。** 张力戏里台词是张力的敌人——说破了就没了。

| 情况 | 处理 |
|---|---|
| 最高张力处 | **不写台词**，只写呼吸与眼神 |
| 必须说话 | 写**短句**（≤10 字），且是动作性语言（"别动"、"让开"） |
| 情绪表白 | 移到**破防之后**，不要放在张力峰值上 |
| 隐晦双关 | ❌ 一律删除（命中"隐晦低俗语言使人产生性联想"） |

## 6. 与 H3 硬阻断的关系（重要：这些技法天然安全）

这是我们体系的独特优势——**张力技法与 H3 的能力边界高度契合**：

| H3 硬阻断 | 张力技法如何规避 |
|---|---|
| **持续接触 / 物理接触崩坏** | 六大技法**本来就不拍持续接触**——距离、眼神、气息全部是"未接触" |
| **布料 / 液体动力学** | 只写"衣袖微响""发丝扬起"这类**可静态描述**的次级运动 |
| **手部精细动作** | 微观接触用**手背相贴 / 指尖并拢**，正落在手部三档降级的第 2 档 |
| **中景全身易崩** | 张力戏大量用**特写与大特写**（眼 / 手 / 面部），**特写比中景稳** |
| **长镜头末帧漂移** | 张力戏用 **Static Shot** 为主，恰好是最稳的运镜 |
| **可读文字** | 无影响 |

> **结论**：拍张力戏比拍动作戏对 H3 更友好。
> 你不需要在"有看点"和"不崩坏"之间取舍——**技法本身同时满足两者**。

**唯一需要额外注意的**：双人同框时的一致性。
两人同框 + 距离极近 = 模型容易把两人融合。对策：

```
① 两人描述串全部写进锁定块，逐字复制
② 写绝对画面位置："她站在画面左三分之一，他站在画面右三分之一"
③ 收尾句锁住："双方间距全程不变"
④ 相似角色（如兄弟 / 双胞胎）绝对不要放在同一张力镜里
```

## 7. 原文改写：从「省略式」到「张力式」

以实际拆解过的段落为例，展示两种改法的差异。

### 7.1 出浴 / 更衣类

| 改法 | 写法 | 效果 |
|---|---|---|
| ❌ 省略式 | 她走进浴室（切）她走出来 | 中间空白，观众出戏 |
| ✅ **张力式** | 他在门外，门缝透出光与水汽声；他坐着不动，视线落在门缝的光上；门内水声停了 | **拍等待的人，不拍里面的事**——他的等待本身就是张力 |

```text
【EN】
A medium shot frames him seated on the sofa, facing the bathroom door.
A line of warm light falls across the floor from the gap under the door.
He does not move. Water runs behind the door, then stops.
The camera holds a static shot.
By the end of the shot he is still seated, his gaze fixed on the line of light.
Do not let him stand up at any point in the shot.

【中】
中景框着他坐在沙发上，面朝浴室门。门缝下透出一道暖光横在地板上。
他没有动。门后有水声，然后停了。镜头固定。
到本镜结束他仍坐着，视线定在那道光线上。本镜全程他不站起来。
```

### 7.2 整夜 / 事后类

| 改法 | 写法 | 效果 |
|---|---|---|
| ❌ 省略式 | 时间流逝空镜（窗帘由暖变冷） | 只有转场功能，无情绪 |
| ✅ **张力式** | 天亮后：床边两双鞋、窗帘缝透进的光、一只手从被沿滑落、两人各自醒着的眼睛 | **用结果制造想象**，且每个物件都是叙事证据 |

```text
【EN】
A wide shot frames the bedroom at first light. Grey daylight comes in through
a gap in the curtains. Two pairs of shoes stand side by side on the floor
beside the bed. One hand rests on the edge of the quilt, fingers loose.
She is awake, her eyes open, looking at the ceiling. He is awake, looking at her.
The camera holds a static shot.
By the end of the shot neither has spoken or moved.

【中】
全景框住天光初亮的卧室。灰白日光从窗帘缝隙透进来。
床边地板上并排放着两双鞋。一只手搭在被沿上，手指松着。
她醒着，眼睛睁着看天花板。他醒着，看着她。镜头固定。
到本镜结束两人都没说话也没动。
```

> **这个镜头的信息密度极高**：两双鞋 = 有人过夜；
> 各自醒着 = 关系有裂痕；他不看天花板而看她 = 他还在意。
> **没有一句台词、没有一个露骨画面，观众全看懂了。**

### 7.3 强吻 / 亲密接触类

| 改法 | 写法 | 效果 |
|---|---|---|
| ❌ 直给 | 他吻住她 | 命中红线 |
| ❌ 省略 | 他转身走了 | 没看点 |
| ✅ **差一点 + 打断** | 他靠近到一掌宽停住 → 她没有退 → 门铃响，两人分开 | **张力峰值留在"差一点"，且打断正好是卡点** |

### 7.4 改写三原则

```
① 拍反应，不拍行为 —— 拍旁观者/等待者的脸，比拍事件本身更有张力
② 拍结果，不拍过程 —— 两双鞋、散开的领带、天光，让观众自己推
③ 拍未完成，不拍已完成 —— 停在"差一点"，打断即卡点
```

## 7.6 完整改写案例：从省略式到张力式

以实际拆解过的《挟恩图报后发现认错人了》中的段落为例，完整走一遍。

### 原文情境

> 时安洗完澡出来，蒋筱筱已经等在卧室。原文此处有明确的成人描写。

### ❌ 省略式改法（早期做法）

```
A 入镜（2s）：浴室门缝透光，水声停了
B 主镜（11s）：时间流逝空镜，窗帘由暖橙渐变到冷白
C 出镜（2s）：天光透进卧室
```

**问题**：只有转场功能。观众知道"过去了"，但不知道**他们之间发生了什么、关系变成什么样**。
而这恰恰是下一集的情绪基础——丢了它，后面的剧情就悬空了。

### ✅ 张力式改法

```text
【A 入镜 · 2s · FL2VA】
A medium shot frames him seated on the sofa facing the bathroom door.
A line of warm light falls across the floor from the gap under the door.
Water runs behind the door, then stops.
The camera holds a static shot.
By the end of the shot he is still seated, his gaze fixed on the line of light.
Do not let him stand up at any point in the shot.

【B 主镜 · 11s · T2VA】
A wide shot frames the bedroom at first light. Grey daylight comes in through
a gap in the curtains. Two pairs of shoes stand side by side on the floor beside
the bed. One hand rests on the edge of the quilt, fingers loose, five fingers,
natural proportions.
She is awake, her eyes open, looking up at the ceiling. He is awake, looking at her.
Neither speaks. A car passes somewhere outside, the sound fading.
The camera holds a static shot, then pushes in with small amplitude at slow speed.
By the end of the shot neither has moved or spoken.
Do not let either of them look away at any point in the shot.

【C 出镜 · 2s · FL2VA】
A close-up frames her hand on the quilt. Her fingers close slowly, gathering
the fabric, then stop. The camera holds a static shot.
By the end of the shot her hand is closed on the quilt and has not moved again.
Do not let the fingers change number at any point in the shot.

overall_soundscape: A car passing outside, fading. One slow breath. The quiet
shift of fabric as a hand closes. Birds starting up somewhere far off.

non_diegetic_music: N/A
```

### 这个改写做对了什么

| 处 | 作用 |
|---|---|
| **两双鞋并排** | 叙事证据：有人留宿。不拍过程，观众自己推 |
| **各自醒着，一个看天花板一个看她** | 关系状态一目了然：她心不在这里，他在意她 |
| **C 出镜的手攥紧被沿** | 情绪外化（心理不可见，转成手部动作）。且是**下一集的钩子** |
| **全程无台词** | 最高张力处不写台词 |
| **无 BGM**（`N/A`） | 留白，只留环境音 |
| **手部正向锚定** | `fingers loose, five fingers, natural proportions` —— 手部三档降级第 2 档 |

**信息密度对比**：

| | 省略式 | 张力式 |
|---|---|---|
| 观众知道发生了什么 | ❌ | ✅（两双鞋） |
| 观众知道关系变成什么样 | ❌ | ✅（醒着的眼神方向） |
| 有情绪钩子接下一集 | ❌ | ✅（攥紧的手） |
| 合规 | ✅ | ✅ |
| H3 崩坏风险 | 低 | 低（全用 Static Shot + 特写） |

> **关键结论**：张力式不是"在省略式上加料"，而是**换了一个信息载体**——
> 从"拍事件"换成"拍证据 + 拍反应"。同样的合规约束下，信息量反而更大。

## 8. 分镜层面的排布建议

### 8.1 一段 15 秒张力戏的三镜分配

| 镜位 | 时长 | 内容 |
|---|---|---|
| **A 入镜** | 2s | 建立距离（两人位置 / 空间关系） |
| **B 主镜** | 11s | **接近 → 停在差一点 → 停顿（给足时长）** |
| **C 出镜** | 2s | 打断 / 视线转移 / 谁先退开 |

> B 主镜的 11 秒里，**"停在差一点"要占 4–6 秒**。
> 停顿给得越足，张力越强。不要急着推进。

### 8.2 跨段落的递进

张力戏不适合一段讲完。**分在连续 2–4 段里逐层递进**：

```
P3  距离：两人在同一空间，距离在缩短
P4  眼神：第一次对视，谁先移开
P5  微接触：递东西时手指相碰
P6  气息：距离近到能听见呼吸
P7  打断 / 破防 / 反转
```

每段只推进一层——正好符合「15 秒 = 1 个情绪转折」的约束，
而且**每段结尾都能卡点**，连续留钩子。

### 8.3 跨集张力弧线（多集剧别每集都拉满）

**常见错误**：每集都安排一次"差一点"，看到第 5 集观众就麻了。

张力需要**起伏**，不是持续爬升。建议按这条曲线排：

```
集 1–2   建立吸引（距离 / 眼神为主，强度 ★★）
集 3     第一次近距离（微接触，★★★）
集 4     回落（误会 / 冷战 / 第三方介入，★）—— 关键：要有低谷
集 5–6   重建 + 破防（反差破防，★★★★）
集 7     危机（外部压力，张力来自情节不是距离）
集 8     释放（一次点到即止的接触或告白，★★★）
```

**三条排布规则**：

| 规则 | 说明 |
|---|---|
| **低谷必须有** | 没有低谷，高峰就不成立。冷战、误会、第三方的集数不是凑数，是给下一次张力蓄力 |
| **强度逐集抬升，但每次抬一级** | 从眼神 → 指尖 → 气息 → 破防，不要跳级 |
| **释放点控制在全剧 1–2 次** | 释放太频繁，张力就通胀了 |

> **技巧**：把"低谷集"当成张力工具用。
> 观众在低谷集里积累的"想要他们在一起"的期待，会在下一次接近时集中释放——
> 那一次的张力，比连续十次接近都强。

## 9. 检查清单

### 9.1 合规自检（每条必过）

```
□ 有没有"集中细致展现"亲密行为？（应无集中、无细致、无连续）
□ 这段亲密表达有没有叙事功能？（无叙事功能 → 删）
□ 有没有聚焦敏感部位？（应无）
□ 着装是否过分暴露？（应否）
□ 台词有没有隐晦双关 / 性暗示？（应无）
□ 有没有直接展示性行为？（绝对禁止）
□ 时长是否控制在点到即止？（单镜亲密度不超过 2 秒）
□ 有没有用"差一点 + 打断"替代直给？
```

### 9.2 技法自检

```
□ 六大技法至少用了两种？（建议距离 + 未完成组合）
□ 停顿给足了吗？（主镜里"差一点"的状态占 4–6 秒）
□ 声音层承担张力了吗？（呼吸 / 衣物摩擦 / 环境静止）
□ 台词是不是过多了？（最高张力处应无台词）
□ 双人同框的位置写绝对画面位置了吗？
□ 手部用了三档降级吗？（手背相贴 / 指尖并拢 / 五指）
□ 破防是分层次递进的吗？（不要一个镜头演完）
```

### 9.3 H3 技术自检

```
□ 双人锁定块三镜逐字一致
□ 间距/姿态有"全程不变"的收尾句
□ 每镜一个运镜（这类戏建议 Static Shot 为主）
□ 每镜最多 1 句 Do not，内容限 B 类
□ 采样步数 ≥6（出片档）
□ 高风险镜（手部 / 双人同框）有备选方案
```

## 10. 反面清单（这些做法要避免）

| ❌ 做法 | 问题 | ✅ 改法 |
|---|---|---|
| 把亲密戏整段删掉 | 丢失看点，观众出戏 | 保留张力，去掉露骨 |
| 用空镜桥接代替 | 只有转场功能，无情绪 | 用"拍结果"替代"拍过程" |
| 靠暴露着装制造看点 | 命中红线，且会诱导模型生成失控 | 靠距离 / 眼神 / 留白 |
| 台词说破情绪 | 张力归零 | 不写台词 / 只写动作性短句 |
| 一个镜头推到底 | 没有停顿，张力出不来 | 推—停—推—停，停顿占主镜一半 |
| 整段慢动作 | 拖沓 | 只在关键一瞬用，且配合速度对比 |
| 隐晦双关台词 | 命中"隐晦低俗语言" | 删除，改用动作表达 |
| 双人同框不写位置 | 模型容易把两人融合 | 写绝对画面位置 + 间距不变的收尾 |

## 13. 一句话速查

```
红线 = 集中细致 + 单纯感官刺激 + 明显性挑逗（三个限定词缺一不违规）
     ↓
所以：有叙事目的 + 点到即止 + 留白 = 安全且好看

六大技法：距离 · 眼神 · 微接触 · 气息 · 反差破防 · 未完成
核心是「未完成」——在预期高潮前切走，让观众脑补

改写三原则：拍反应不拍行为 · 拍结果不拍过程 · 拍未完成不拍已完成

节奏：推—停—推—停，停顿处才是张力峰值（主镜里占 4–6 秒）
声音：呼吸 / 衣物摩擦 / 环境静止，BGM 撤掉做留白
台词：最高张力处不写台词

H3 优势：这些技法天然规避持续接触、布料、长镜头等硬阻断，
       且大量用特写——特写比中景稳
```
