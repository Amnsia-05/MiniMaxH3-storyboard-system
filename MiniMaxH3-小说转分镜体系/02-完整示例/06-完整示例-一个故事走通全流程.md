# 完整示例 · 一个故事走通全流程

> 本文件演示如何用主模板把**一段 15 秒**从大纲做到可提交的 H3 提示词。
> 示例故事为演示而写，角色与场景可整体替换为你自己的剧本。

---

## 〇、示例设定

| 项 | 值 |
|---|---|
| 剧名 | 《重生之我不做冤大头》（示例） |
| 类型 | 都市重生 · 3D 次世代漫剧 |
| 单集时长 | 120 秒（8 段） |
| 本段位置 | **E01-S03**（第 1 集第 3 段，时间码 00:00:30 – 00:00:45） |
| 本段叙事任务 | **反转 / 爽点**（承接 P2 的矛盾，本段给第一次情绪释放） |
| 本段唯一信息点 | 林晚拒绝签署这份合同 |
| 本段唯一情绪转折 | 从被压制 → 反手压制 |
| 切分方案 | **主镜优先 2 / 11 / 2**（衔接镜任务轻，只摆中间态） |
| 场景 | SC_02 律所会议室 |

**为什么选「主镜优先 2/11/2」**：本段两个衔接镜都只承担**动作延续**（站起一半 / 转身一半），任务极轻，2 秒足够。符合 §3.2.6 决策规则的第一条。

## 一、段级大纲（模块二 §2.2）

```markdown
### E01-S03《她不签》

- **时间码**：00:00:30 – 00:00:45（严格 15s）
- **本段唯一信息点**：林晚拒绝签署这份合同
- **本段唯一情绪转折**：被压制 → 反手压制
- **叙事任务**：反转 / 爽点
- **场景**：SC_02 律所会议室
- **出场角色**：CH_01 林晚（主角）、CH_02 陈总（配角）
- **台词总量预算**：≤ 47 字（实际用 27 字）
- **与上一段的衔接方式**：动作延续——上一段 C 出镜停在"站起一半"，本段从这里接上
- **与下一段的衔接方式**：动作延续——本段 C 出镜停在"转身一半"，下一段续完
```

## 二、分镜表（模块三 §3.7）

| 字段 | A 入镜 | B 主镜 | C 出镜 |
|---|---|---|---|
| **镜号** | E01-S03-C1 | E01-S03-C2 | E01-S03-C3 |
| **时长** | 2.0s | 11.0s | 2.0s |
| **时间码** | 00:00:30.0–32.0 | 00:00:32.0–43.0 | 00:00:43.0–45.0 |
| **景别** | 中景 | 中近景 → 近景 | 大特写（侧脸） |
| **机位角度** | 平视 | 平视 | 平视，侧面 45° |
| **运镜** | `Static Shot` | `Push In with small amplitude at slow speed` | `Static Shot` |
| **生成方式** | T2VA（并入主请求） | T2VA | T2VA |
| **画面内容** | 林晚**已在半起状态**，双手撑桌，膝盖约 120 度 | 她站直，拿起合同，走向窗边，说完台词 | 她开始转向门口，肩膀转过约 45 度，**动作未完成** |
| **构图/主体位置** | 主体居画面中偏左，视线向下 | 主体居画面中偏右，视线向画外 | 侧脸占画面右侧 2/3，视线向右 |
| **人物** | CH_01 | CH_01 | CH_01 |
| **台词** | 无 | 「陈总，这份合同我一个字都不会改。要么重签，要么法庭见。」（27 字） | 无 |
| **匹配锚点** | 承接上一段末帧姿态 | 光位：右前上方主光 | 交出"转身 45 度"中间态 |
| **入点衔接** | 动作延续（接上一段半起姿态） | 硬切 | 硬切 |
| **出点衔接** | 硬切 | 硬切 | 动作延续（交下一段续完） |
| **采样步数** | 6 | **8**（有台词 + 长动作） | 6 |
| **风险等级** | 低（无手部特写） | 中（手部持纸 + 台词） | 低（只拍侧脸） |
| **备选方案** | 降为「手部撑桌特写」，完全避开全身 | 若手部持纸崩 → 改为「合同已摊开在桌上，她手按在纸面上」 | 若转头崩 → 改为「固定侧脸，只有眼神向右移动」 |

**自动校验结果**：

```
✅ ① 时长和：2.0 + 11.0 + 2.0 = 15.0s
✅ ② 硬下限：每镜 ≥ 1.5s
✅ ③ 信息镜：B 主镜 11.0s ≥ 3.0s
⚠️ ④ 悬殊比：11.0 ÷ 2.0 = 5.5（超过建议值 2.5，但合法；量产时若重生成代价过高则退回 4.5/6/4.5）
✅ ⑤ 台词：27 字 ≤ 47 字
✅ ⑨ 备选方案：三镜均已填写
```

## 三、中文详版提示词（模块六）

### 3.1 共用锁定块（三镜逐字复制，约 470 汉字）

```
同一名女性贯穿全部三镜：28 岁，鹅蛋脸，齐肩黑色直发发尾微内扣，深色眉毛，
深棕色杏仁形眼睛，鼻梁挺直，唇形偏薄，下巴圆润，肤质自然，右侧眉尾有一颗小痣。

身穿米白色无标识圆领纯棉 T 恤，外搭深卡其色长款风衣，下身深蓝色直筒牛仔裤，
白色低帮帆布鞋。左耳垂佩戴一只银色小圆环耳环，始终在左耳垂上，大小形状不变，
不被摘下或替换。全程不增加、不减少任何配饰。

律所会议室，日景。唯一光源为画面右前上方的落地窗，单一柔和自然光自右前上方打来，
色温偏冷；背景为深灰色长条会议桌与一面留白墙面，背景简洁无杂物；
画面中不出现任何文字、字母、数字、标识或水印。

实拍电影感，写实风格，35mm 镜头，浅景深，青绿与琥珀色调，中等反差，
自然皮肤质感，轻微胶片颗粒，无风格化滤镜，色温与反差在三镜内完全一致。
```

### 3.2 A 入镜（约 210 汉字）

```
① 中景，林晚位于画面中偏左，身体前倾约 30 度，双手掌心向下平按在会议桌边缘。
② 她的指尖在桌面轻压一次，然后重心前移，然后身体从桌面抬起约三分之一。
③ 无对白，嘴唇闭合。
④ 风衣下摆随起身轻微晃动，窗外天光在她手背上投下稳定的亮斑。
⑤ 镜头固定不动。
⑥ 光位与共用锁定块一致。
⑦ 结束时她停在半起状态：膝盖弯曲约 120 度，上身前倾，动作明确未完成的姿势。
```

> **关键**：⑦ 给出了可量化的中间态（膝盖 120 度），下一段能逐字抄回。

### 3.3 B 主镜（约 320 汉字）

```
① 中近景，承接上一镜的半起姿态，林晚位于画面中偏右，视线朝向画外右侧。
② 她先缓缓站直，然后双手拿起桌上的合同，然后转身走向窗边，然后在窗前停住。
③ 她音色偏低、语气平稳、语速中速偏慢 (S1) 说：<d>[Chinese] 陈总，这份合同我一个字都不会改。要么重签，要么法庭见。</d>
④ 风衣下摆随步伐摆动，合同纸面在她手中轻微起伏，窗光在她侧脸形成稳定的明暗分界。
⑤ 镜头缓慢小幅推近，从中近景推到近景。
⑥ 光位与共用锁定块一致，窗光作为唯一光源保持不变。
⑦ 结束时她侧身立于窗前，双手垂于身体两侧，合同叠好握在右手中，视线落在画外。
    Do not 在画面任何位置出现文字或让合同上的字迹变得清晰可读。
```

> **手部处理**：合同是"大物件握持"，手指被纸面遮住，规避了精细持物风险。
> **文字处理**：主动声明合同字迹不可读，避免模型去赌字形。

### 3.4 C 出镜（约 190 汉字）

```
① 大特写，她的侧脸占画面右侧三分之二，视线朝向画面右方。
② 她先眨一次眼，然后下巴微微抬起，然后头部开始转向门口方向。
③ 无对白，嘴唇闭合。
④ 发丝随转头从肩头滑落，窗光在她的颧骨上形成一条稳定的高光带。
⑤ 镜头固定不动。
⑥ 光位与共用锁定块一致。
⑦ 结束时她的肩膀已转过约 45 度，转向动作明确未完成的姿势，为下一段留出接续点。
```

### 3.5 声音层（约 130 汉字）

```
overall_soundscape：
会议室安静的底噪，手掌按在桌面上的一次轻压声，纸张被拿起的摩擦声，
两下平稳的脚步声，风衣布料随步伐的摩擦声。

non_diegetic_music：
低频弦乐，极慢速度，在她说完台词后进入，音量在最后一秒淡出。
```

### 4.2 转译要点对照

| 中文详版 | 官方格式 | 说明 |
|---|---|---|
| 锁定块中文描述 | 展开成英文，置于 `[Shot 1]` 开头 | 官方示例也是这个做法 |
| 「然后…然后…」 | `then ... then ...` | 显式时序，防并发动作 |
| 台词 + `(S1)` | `<d>[Chinese] 原话</d>` | 描述在标签外，原话在标签内 |
| 「镜头固定不动」 | `The camera holds a static shot` | 官方术语 |
| 「缓慢小幅推近」 | `pushes in with small amplitude at slow speed` | 类型 + 幅度 + 速度 |
| 环境音 / 配乐 | `overall_soundscape` / `non_diegetic_music` | 分列，不混写 |
| 收尾复述 | 段落末尾再写一次身份与光位 | 首尾双写，防信息埋没 |

### 4.3 若要拆成独立请求（跨段锁帧版）

把 A 镜改成 **FL2VA**，用上一段的尾帧作为首帧、本段 A 镜末帧作为尾帧：

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the 2.00-second mark of the target video.

integrated_multimodal_description: [Shot 1] ...（同上）
```

C 镜同理，用下一段的首帧作为尾帧。

> ⚠️ **FL2VA 默认单镜**：官方原文 *"FL2VA generally favors a single shot... Use multiple shots only when they are explicitly specified."*
> 所以拆开做时，每个请求就写**一个**镜头，不要在一个 FL2VA 请求里塞多镜。

## 五、漏洞检查报告（模块八）

### 5.1 第一层：结构检查

```
✅ 1. 时长和 = 15.0s，0.5s 网格
✅ 2. 每镜 ≥ 1.5s（2.0 / 11.0 / 2.0）
✅ 3. 信息镜 B = 11.0s ≥ 3.0s
⚠️ 4. 悬殊比 5.5（合法，但量产需评估重生成代价）
✅ 5. 台词 27 字 ≤ 47 字
✅ 6. 锁定块三镜逐字一致
✅ 7. 每镜 1 个运镜且为官方术语（Static / Push In / Static）
✅ 8. A、C 无 Do not 句；B 有 1 句，且前面有正向描述
✅ 9. 三镜均填了备选方案
```
