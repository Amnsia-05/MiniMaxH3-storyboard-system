# H3 单镜提示词模板 v1
### 面向「15 秒 3 镜」AI 漫剧 · 基于 MiniMax H3 官方四段式结构

---

## 0. 字数预算总账（先说清楚一处算术）

你给的口径是「每镜新增 200–350 汉字，三镜合计 1200–1800 汉字」。这两句对不上：
`200–350 × 3 = 600–1050`，到不了 1200–1800。

**我按"三镜合计＝全套提示词总量（含锁定块与声音层）"来落地，这样两条口径能同时成立：**

| 组成 | 预算（汉字） | 出现次数 |
|---|---|---|
| ① 共用锁定块（角色 + 服化道 + 场景光照 + 画风） | **400–600** | 三镜逐字复制，计 1 次 |
| ② 每镜新增指令（六段） | **200–350 × 3** | 每镜 1 次 |
| ③ 声音层（`overall_soundscape` + `non_diegetic_music`） | **100–200** | 计 1 次 |
| **全套合计** | **1100–1850** | ✅ 落在 1200–1800（中位约 1470） |

另留 **7,000 字符**官方上限的余量：全套 1,850 汉字 ≈ 1,850 字符（中文 1 字 = 1 字符），**仅用掉上限的 26%**，还有充足空间加参考图对齐说明。

## 2. 块①：共用锁定块（400–600 汉字）

**铁律：三镜内逐字复制，一个字都不改。** 改一个词就可能触发身份漂移（Verbatim Rule）。

```
【角色身份串 · 约 120 汉字】
同一名女性贯穿全部三镜：28 岁，鹅蛋脸，齐肩黑色直发，发尾微内扣，
深色眉毛，深棕色杏仁形眼睛，鼻梁挺直，唇形偏薄，下巴圆润，
肤质自然，面部无任何痣或纹身。

【服装与随身资产串 · 约 150 汉字】
身穿米白色无标识圆领纯棉 T 恤，外搭深卡其色长款风衣，
下身深蓝色直筒牛仔裤，白色低帮帆布鞋。
左耳垂佩戴一只银色小圆环耳环，耳环始终在左耳垂上，大小形状不变，不被摘下或替换。
右手无名指佩戴一枚哑光金色印章戒指，全程在同一根手指上，不变形、不换手。
全程不增加、不减少任何配饰。

【场景与光位串 · 约 120 汉字】
室内客厅，夜景。画面右侧有一盏落地灯作为唯一可见光源，
单一柔和主光自画面右前方 45° 打来，色温偏暖；
背景为浅灰色布艺沙发与一面留白墙面，背景简洁无杂物，
画面中不出现任何文字、字母、数字、标识或水印。

【画风串 · 约 100 汉字】
实拍电影感，写实风格，35mm 镜头，浅景深，背景轻微虚化，
青绿与琥珀色调，中等反差，自然皮肤质感，轻微胶片颗粒，
无风格化滤镜，色温与反差在三镜内完全一致。
```

## 3. 块②：每镜新增指令（200–350 汉字 / 镜）

### 六段顺序 + 字数预算

| 段 | 名称 | 预算（汉字） | 官方要素对应 | 写什么 |
|---|---|---|---|---|
| ① | **subject 主体与开场构图** | 50–80 | STYLE + INITIAL FRAMING + SUBJECT + ENVIRONMENT | 景别、主体位置在画面哪里、朝向、开场姿态 |
| ② | **时序动作节拍** | 50–90 | SMALL NATURAL MOVEMENT → ACTION ONSET → VISIBLE PHYSICAL RESPONSE | **用「然后」串联，禁用「同时」**；每个动作给明确终点 |
| ③ | **对白**（可选） | 30–80 | SPEAKER + (S1) + DELIVERY: [Language] "台词" | 说话人描述与语气**放标签外**；只有语言标签和台词**放里面**；台词用**英文双引号** |
| ④ | **环境反应** | 20–40 | SYNCHRONIZED DIEGETIC SOUND / VISIBLE ENVIRONMENTAL RESPONSE | 次级运动：衣摆、发丝、热气、光影变化、画内物理音 |
| ⑤ | **运镜** | 30–50 | CAMERA MOTION TYPE + AMPLITUDE + SPEED | **只用官方术语，一镜一个运镜**；幅度/速度仅在必要时加 |
| ⑥ | **光影风格** | 20–40 | — | 只写本镜与锁定块的**差异**，无差异就写"光位与锁定块一致" |
| ⑦ | **收尾状态** | 30–60 | FINAL CHARACTER STATE + FINAL COMPOSITION | 本镜最后一帧是什么样，为下镜留接口 |
| — | **收边（可选）** | ≤25 | — | **最多 1 句 `Do not ...`**，且前面必须先有正向描述 |
| | **合计** | **230–465** | | 常规镜头落在 **250–320** 最稳 |

> 六段与官方 11 要素的映射：team-lead 的六段是官方 11 要素的**中文写作骨架**，主体①=前 3 要素，动作②=中间 3 要素，环境④+运镜⑤=中间 2 要素，收尾⑦=最后 2 要素。官方 11 要素中「REFERENCE CONTINUITY」已上提到共用锁定块。

### 单镜填空模板

```
【Shot N】
①  <景别> frames <主体> at <画面位置>，<朝向>，<开场姿态>。
②  <微小自然运动>，然后<动作 1，有明确终点>，然后<动作 2，有明确终点>。
③  <说话人外观描述> with <音色与语气> (S1) says: [Chinese] "<逐字台词>"
④  <次级运动：发丝/衣摆/光影/热气>；<画内物理音>。
⑤  The camera <官方运镜术语> with <small/large> amplitude at <slow/medium/fast> speed <起点→终点>。
⑥  <本镜光位差异，无差异则写"光位与共用锁定块一致">。
⑦  By the end of the shot, <最终人物状态> + <最终构图>。
    Do not <最多一句否定收边>。
```

## 4. 块③：声音层（100–200 汉字）

```
overall_soundscape:
客厅夜晚的安静底噪，手机屏幕轻触声，布料摩擦声，
她一次缓慢的吸气，落地灯电流极轻微的嗡声。

non_diegetic_music:
低频弦乐，极慢速度，音量在第二镜推起、第三镜结束前淡出。
（不要留空；无配乐时明确写：no music）
```
**判别规则**：问一句"**画面里的人能不能听见**"——能听见 → `overall_soundscape`；只有观众能听见 → `non_diegetic_music`。

## 7. 一条必须提前告知的结构约束

**H3 官方的多镜时间戳机制要求各镜切分大致均衡，不支持"11 秒主镜 + 2 秒 + 2 秒"的悬殊切分。**

- 官方镜头数预算：**13–15 秒 → 2–4 镜**。15 秒 3 镜**本身完全可行** ✅
- 但推荐的切法是 **约 5 / 5.5 / 4.5 秒**（如上例 00:00 / 00:05.000 / 00:10.500）。
- 若客户坚持"11 秒主镜 + 两个 2 秒衔接镜"，则**不能放在同一次请求里**，必须拆成多次生成 → 那么「跨请求左右方位 / 180° 轴线」重新变回硬阻断，且会失去一次生成共享上下文的一致性红利。

**建议**：与 storyboard-craft-research 的「主镜 + 双衔接镜」范式对齐时，明确二选一——
- **方案 A（推荐）**：三镜均衡切分，一次请求生成 → 一致性最好、成本最低，但主镜时长从 11 秒降到约 5 秒。
- **方案 B**：保留 11 秒主镜 → 拆成 3 次请求，主镜单独生成，两衔接镜各 2 秒单独生成 → 需接受跨请求一致性风险与「后置」处置。

我已把这条同步给 storyboard-craft-research，请 team-lead 在范式层面拍板。
